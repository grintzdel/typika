# Typika

Un hub open source et gratuit de templates de code **exécutables dans le navigateur**, pour apprendre l'architecture,
les principes SOLID, les design patterns et la POO par la pratique.

Chaque template est un vrai projet, accompagné :

- d'une **base** qui montre le code avant le pattern ;
- d'une **visite guidée** ancrée dans le code ;
- d'**exercices** — notamment `refactor` : une exigence pénible sans le pattern, triviale avec ;
- de **variantes** en TypeScript, JavaScript, Go et Kotlin, comparables côte à côte.

> Statut : M1 (socle) en cours — voir la [roadmap](docs/roadmap.md).
