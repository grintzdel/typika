# Strategy base: shipping options

The starting point of `strategy-ts`. A small shop offers standard and express shipping, and `ShippingQuote` prices
both with one `if / else` chain on the shipping option.

The code works and its tests pass. Open `strategy-ts` to see the same behaviour with the Strategy pattern, or start the
`add-pickup-point-option` exercise there to feel why the pattern exists.

## Run it

Requires Node.js 23.6 or later.

```sh
npm install
npm start
npm test
```
